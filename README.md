# Описание программы: Мистическое Таро на PyQt6

`0.5.py` — десктопное приложение-таролог на Python 3 с использованием PyQt6.  
Пользователь выбирает расклад, при желании вводит вопрос, нажимает кнопку — карты «раздаются» с анимацией, после чего генерируется развёрнутое текстовое толкование на русском или английском языке.

---

## Возможности

| Функция | Описание |
|---|---|
| 🔮 **9 видов раскладов** | Карта дня, Да/Нет, Прошлое–Настоящее–Будущее, Любовь, Карьера, Деньги, Здоровье, Выбор пути, Кельтский крест |
| 🃏 **Полная колода 78 карт** | 22 Старших Аркана + 56 Младших (Жезлы, Кубки, Мечи, Пентакли), для каждой — прямое и перевёрнутое значение |
| ✨ **Анимация переворота карт** | Карты «раскрываются» по одной с `QPropertyAnimation`, показывая рубашку → лицо |
| 🔊 **Синтез звука без файлов** | WAV-эффекты (flip / reveal / final) генерируются программно через `wave` + `struct` и кэшируются во временной папке |
| 🌍 **Двуязычный интерфейс** | Переключение RU ⇄ EN на лету, все тексты, позиции и трактовки меняются |
| 🎴 **Комбинации карт** | ~16 парных сюжетов (Смерть+Солнце, Башня+Звезда и др.), автоматически вплетаются в толкование |
| 🖥️ **Полноэкранный режим** | `F11` — переключить, `Escape` — выйти, `Ctrl+N` — новый расклад |
| 🎨 **Кастомная отрисовка карт** | Каждая карта рисуется вручную через `QPainter`: градиенты, узоры рубашки, эмодзи-символ, бейдж «прямая/перевёрнутая» |

## Архитектура и структура файла

### 1. Подавление шума Qt (строки 1–40)
До импорта любых модулей PyQt6 устанавливается переменная `QT_LOGGING_RULES`, а также `qInstallMessageHandler` — чтобы в консоль не сыпались служебные сообщения от ffmpeg/Qt Multimedia.

### 2. Утилита шрифтов (строки 53–61)
`make_emoji_font()` — подбирает кроссплатформенный эмодзи-шрифт:

```python
f.setFamilies([
    "Segoe UI Emoji", "Apple Color Emoji", "Noto Color Emoji",
    "Symbola", "DejaVu Sans",
])
```

### 3. Звук (строки 67–150)
- `_tone()`, `_chime()`, `_chord()` — генераторы волновых форм (обычный тон, «колокольчик» с обертонами, аккорд с затуханием).
- `SoundPlayer` — ленивая генерация WAV в `%TEMP%/tarot_sounds_v1`, обёртка над `QSoundEffect`. Корректно деградирует, если `PyQt6.QtMultimedia` недоступен (`HAS_SOUND=False`).

### 4. Интернационализация (строки 156–330)
- Словари `T` (тексты UI и толкований) и `POS` (названия позиций).
- Функции `set_lang()`, `tr(key, **kw)`, `pos_name(key)` — единая точка доступа ко всем строкам.

### 5. Данные карт (строки 336–820)
- `CARDS` — список из 78 кортежей формата:

```
(key, эмодзи, знак_для_да/нет,
 (RU: имя, значение, совет, значение_перевёрнутое, совет_перевёрнутый),
 (EN: имя, значение, совет, значение_перевёрнутое, совет_перевёрнутый))
```

- `CARD_BY_KEY` — быстрый поиск.
- `card_info(key, lang, reversed_)` — возвращает `(имя, значение, совет)` с учётом ориентации.

### 6. Комбинации карт (строки 826–905)
- `COMBOS` — словарь пар `(key1, key2) → текст` на двух языках.
- `find_combos()` — находит пересечения с выпавшими картами.

### 7. Расклады (строки 911–975)
- `SPREADS` — список словарей с `id`, названием, подсказкой и списком позиций.

### 8. `TarotCardWidget` (строки 981–1170)
Собственный виджет карты:

- `_flip` — прогресс анимации `0.0–1.0`, отрисовка через `cos(flip·π)` даёт эффект 3D-переворота.
- `_paint_back()` — фиолетовая рубашка с радиальным градиентом и сеткой из диагональных линий.
- `_paint_front()` — кремовый лист с золотой рамкой, эмодзи-символом (переворачивается, если карта reversed), названием, позицией и цветным бейджем прямой/перевёрнутой.

### 9. `TarotApp` — главное окно (строки 1174–конец)
- **UI:** заголовок с орнаментом, панель управления (комбо расклада, звук, язык, фуллскрин), поле вопроса, ряд карт, кнопка «Сделать расклад», `QTextEdit` с HTML-результатом.
- **Логика раздачи:** `make_spread()` случайно (без повторов) выбирает N карт, ~30% помечает перевёрнутыми, запускает `QTimer` — карты раскрываются каждые 500 мс.
- **Генерация толкования:** методы `_pred_daily`, `_pred_yesno`, `_pred_ppf`, `_pred_love`, `_pred_three`, `_pred_choice`, `_pred_cross` — каждый формирует HTML с секциями (толкование, синтез, советы, комбинации, финальный вердикт).
- **HTML-хелперы:** `_h_title`, `_h_section`, `_h_p`, `_card_line`, `_combos_block`, `_advice_block`, `_footer_block` — конструкторы стилизованных блоков.

### 10. Точка входа (строки ~1640–конец)
`main()` — устанавливает собственный `excepthook` (чтобы трейсбеки не терялись), создаёт `QApplication`, применяет стиль Fusion, показывает окно.

## Дизайн и эстетика

- **Палитра:** тёмно-фиолетовый фон `#0d0819`, панели `#16102a`, золотой акцент `#d4af37`, кремовый текст `#e8dcc0`.
- **Типографика:** Georgia (serif) для заголовков и толкований, Arial — для служебных элементов.
- **Эффекты:** `QGraphicsDropShadowEffect` под картами с фиолетовым свечением; градиенты — линейные, радиальные и конические.

## Технические детали

| Аспект | Решение |
|---|---|
| Плавность | `QPropertyAnimation` + `pyqtProperty(float)` для кастомного свойства `flipProgress` |
| Отзывчивость | UI не блокируется — раскрытие карт через `QTimer` |
| Безопасность | Обёртки `try/except` вокруг звука, обработчиков, `closeEvent` |
| Память | `old.deleteLater()` при пересоздании таймеров и виджетов |
| Совместимость | Корректно работает без `QtMultimedia` (звук просто отключается) |

## Как пользоваться

1. Запустить: `python 0.5.py`.
2. Выбрать расклад из выпадающего списка.
3. (Опционально) ввести вопрос в текстовое поле.
4. Нажать **«🎴 СДЕЛАТЬ РАСКЛАД»** — карты разложатся и перевернутся.
5. Читать толкование: секции «ТОЛКОВАНИЕ», «РАЗВЁРНУТАЯ ИСТОРИЯ», «СИНТЕЗ», «СОВЕТЫ», «КОМБИНАЦИИ».
6. Переключить язык / звук / фуллскрин — по желанию.  
   Горячие клавиши: `F11`, `Escape`, `Ctrl+N`.
